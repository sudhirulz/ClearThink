The Case File Behind the Case Files

How this thing actually got built — the story and the tech.

The Origin Story

This started in a debate round, not a computer science class. I kept hearing college debaters casually drop terms like "straw man" or "slippery slope" mid-speech — the ideas made total sense to me, but the vocabulary was new, like everyone else was in on something I wasn't.

So I looked into it properly, and it turned into a rabbit hole. Once you know the names, fallacies show up everywhere — interviews, op-eds, an argument with a classmate — but it's not something anyone actually teaches in school. I'm also into Math, Logic, and Linguistics, and this project sits right where those interests meet: could AI make something usually locked away in debate clubs a little more accessible to everyone else?

Busted! is the answer I built — part of ClearThink, a youth-led initiative I run to spread fallacy literacy through workshops and open tools like this one.

Under the Hood

The classifier. The fallacy detector is a roberta-base transformer model, fine-tuned from scratch on a custom dataset covering all 12 categories — the 11 fallacies plus a "No Fallacy" class for sound reasoning. That negative class turned out to matter the most: without it, a model forced to always pick one of 11 fallacies will misfire constantly on ordinary, non-fallacious text.

The dataset. Around 550 labeled examples, hand-designed and iterated over several rounds — including deliberately hard "minimal pairs" (like a genuinely valid logical argument sitting right next to its fallacious twin) to force the model to learn the actual reasoning pattern instead of surface keywords.

Training and evaluation. Fine-tuned in PyTorch using Hugging Face's transformers library, with a held-out validation split tracked every epoch and a separate test set used only for final scoring — currently landing around 98% accuracy on that held-out set.

Deployment. The trained model is hosted as a live inference API on Hugging Face Spaces (free-tier ZeroGPU hardware). When you hit "Run the Scan," this page sends your text there, splits it into sentences, and gets back a label and confidence score for each one.

The specific explanations. The classifier alone can only tell you a label and a confidence number — it can't explain itself in plain language. So there's a second layer: Claude (Anthropic's AI) reads each flagged sentence and writes an explanation and rewrite specific to its actual content, instead of a generic canned definition.
